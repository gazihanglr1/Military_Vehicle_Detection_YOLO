# Dataset Selection Guide

Before importing a dataset:
- identify the owner;
- read the exact license;
- check redistribution and commercial-use permissions;
- record dataset/version/source URL;
- record class names and annotation format;
- preserve required attribution;
- do not assume a downloadable dataset is redistributable.

Metadata template:
```yaml
dataset_name: ""
dataset_version: ""
source_url: ""
license: ""
classes: []
split: ""
```
