# Methodology

1. Select a legally redistributable dataset.
2. Validate/convert annotations to YOLO format.
3. Establish a small-model baseline.
4. Train and record all experiment parameters.
5. Evaluate precision, recall, mAP50, mAP50-95 and latency.
6. Inspect false positives/negatives and difficult cases.
7. Run multi-object tracking on video.
8. Publish reproducible configs and results.

Record dataset version, model, image size, epochs, batch size, hardware, software versions and metrics.
